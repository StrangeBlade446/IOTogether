# IOTogether — Team Contributions & Attribution

## 1. Project Roles & Contributions

- **Lead Full-Stack Engineer & Architect:** Engineered the Next.js 14 App Router architecture, dual-mode database persistence layer, and transactional atomic reservation functions.
- **UI/UX Designer:** Created the technical aesthetic design system, custom circuit-node branding, high-contrast accessible layouts, and interactive state components.
- **Database & Security Engineer:** Designed the PostgreSQL entity relationship model, Row Level Security (RLS) policies, integer paise pricing logic, and append-only audit trail.
- **QA & Testing Lead:** Implemented and executed the automated verification test suite (`scripts/run-tests.ts`), covering concurrency control, date overlap blocking, and lifecycle transitions.
