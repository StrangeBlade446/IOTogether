1. Problem Statement & Architectural Mission 01 / OVERVIEW

The Electronics Resource Paradox

Engineering colleges and school robotics labs routinely possess high-grade electronics—digital storage oscilloscopes, FPGA boards, spectrum analyzers, and sensor kits—that sit idle up to 80% of the academic calendar. Concurrently, student innovators and robotics hackathon teams face severe equipment starvation.

The IOTogether Shared Platform

IOTogether eliminates institutional silos via a unified hardware registry. Verified students borrow items under transparent duration timers; lab heads maintain total inventory control; and automated QR verification ensures physical equipment safety without administrative overhead.

2. User Personas: The Keeper & Seeker Model 02 / PROTOCOL

Keepers (Lab Custodians & Department Heads)

Primary Interface: /sender portal.

  • Inventory Custody: Catalog hardware with spec sheets, manuals, daily rental/deposit rates, and training prerequisites.
  • ID Verification: Inspect uploaded student/staff ID cards prior to approval.
  • Handover Dispatch: Click Manual Verified to generate time-sensitive dynamic Handover QR tokens.
  • Incident Review: Inspect returned equipment and log condition ratings (Pristine, Normal Wear, Damage Report).
Seekers (Student Innovators, Teachers & Makers)

Primary Interface: /receiver portal.

  • Cross-Campus Discovery: Interactive multi-facet search across all institutions with category, pricing, and availability filters.
  • AI Project Recipe Engine: Input project ideas (e.g. "IoT Weather Station") to automatically generate bill-of-materials and reserve kits.
  • Physical Handover Scan: Scan the Lab Head's screen QR code at pickup to instantly activate loan timers.
  • Active Countdown Timers: Live day, hour, minute, and second countdowns to return deadlines.

3. 3D Chamber & Single-Sided Cable Mechanics 03 / THREE.JS

The landing chamber features a real-time 3D simulation constructed directly with vanilla Three.js and WebGL. Rather than a double-ended cable, IOTogether employs an authentic single-sided cable where one end is anchored to an industrial floor terminal, and a single free grabbable plug can be physically connected to either portal socket.

Position-Based Dynamics

RopePhysics.ts implements a 61-node Verlet constraint solver running at 120Hz substeps. Simulates real cable sag, bend stiffness (0.045), air damping (0.994), and floor friction (0.68).

Socket 01: Keeper Portal

Located at x: -2.05, y: 2.24 on the wall. Snapping the single plug into Socket 01 triggers the left Edison bulb into a warm golden amber glow (#f59e0b) and routes to /sender.

Socket 02: Seeker Portal

Located at x: 1.72, y: 2.24 on the wall. Snapping the plug into Socket 02 triggers the right Edison bulb into a radiant electric cyan glow (#06b6d4) and routes to /receiver.

Single-Sided Cable Architecture Highlights

Fixed Floor Terminal: Point 0 is permanently pinned at (0, 0.08, 2.5) with a flanged brass ring and dark rubber boot.

Continuous Dynamic Mesh: CableMesh.ts rebuilds 112 rings × 8 radial facets per frame with dynamic normals for zero-artifact bending.

3D Depth Navigation: Dragging users can scroll the mouse wheel or toggle floating + NEAR / − FAR buttons to move the plug along the Z-plane.

Procedural Audio: Web Audio API synthesizes realistic pitch-swept contact relays upon connection and subtle chirps on disconnect.

7. Technology Stack & Software Design 07 / STACK

Core Framework & State
  • Framework: Next.js 14.2.15 (App Router, Server Actions, Dynamic Routes).
  • Language: TypeScript 5.6 with strict typing across all interfaces.
  • State Persistence: Atomic filesystem JSON store with transaction locks.
  • Currency Arithmetic: Stored strictly in integer paise (₹1 = 100 paise) preventing IEEE 754 floating drift.
  • Security: Session cookies with HMAC signature & role authorization guards.
3D Rendering & UI Polish
  • Graphics Engine: Three.js 0.170.0 (OrthographicCamera, PCF Soft Shadows).
  • Color Grading: ACESFilmic Tone Mapping, 2048×2048 Sun Light Map.
  • Styling System: Tailwind CSS with custom editorial fonts (Instrument Serif, DM Sans, DM Mono).
  • Dock Navigation: Apple-style interactive spring-enlarged dock hidden on landing and active on dashboard pages.
  • Theme: Crisp, warm ceramic studio palette (Background: #f3efe6, Primary: #ba4d2b).
